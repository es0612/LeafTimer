# Issue #75: PR 自動テスト CI ゲート Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PR を出すと GitHub Actions (macOS runner) で `make tests` が自動実行され、green が master マージの必須条件になる。

**Architecture:** 単一 job がローカルと同一の `make tests` を実行する (single source of truth)。Secrets (Keys.plist / GoogleService-Info.plist) は Xcode Cloud の `ci_post_clone.sh` と同じ base64 復元方式を GitHub Secrets で再現。green 実績 → RED 実証 → branch protection の順で有効化する。

**Tech Stack:** GitHub Actions (macos-26 image / Xcode 26.5 default / CocoaPods 1.17.0・SwiftLint 0.65.0 preinstall 済み), gh CLI, make

**Spec:** `docs/superpowers/specs/2026-08-03-ci-gate-design.md` (承認済み)

## Global Constraints

- 作業ブランチ: `feature/75-ci-gate` (作成済み・spec commit 済み)。default branch は **`master`** (`main` ではない)。
- リポジトリ: `es0612/LeafTimer` (public → macOS runner 無料)。
- ビルド/テスト系コマンドの成否は **exit code を直接判定**する。`| tail` 等のパイプフィルタを付けない。付ける場合は shell が zsh のため `${pipestatus[1]}` (小文字・1-indexed) か `set -o pipefail` を使う。
- CI 実行の watch 系 Bash (`gh run watch` / `gh pr checks`) は **timeout を 600000 (10分) に明示**する。タイムアウトしたら同じコマンドを再実行して watch を継続する (冪等)。
- `base64` を単一行入力欄・env var に渡す時は必ず `| tr -d '\n'` で 1 行化する (macOS base64 は 76 文字で折り返すため)。
- コミットは各 Task 末尾で行い、メッセージ末尾に Co-Authored-By / Claude-Session トレーラーを付ける。
- YAML 内のパス指定: リポジトリルート基準 (`app/...`)。Bash でパスを組み立てる時は絶対パス (`/Users/shinya/workspace/claude/LeafTimer/...`) を使う。

### Task 2: workflow YAML 作成 + 静的検証 + commit

**Files:**
- Create: `.github/workflows/pr-tests.yml`

**Interfaces:**
- Consumes: Task 1 の Secrets 2 件
- Produces: check 名 **`pr-tests`** (job の `name:`)。Task 3 が PR で起動を確認し、Task 5 が branch protection の required context として登録する。

- [ ] **Step 1: workflow ファイルを作成**

`.github/workflows/pr-tests.yml` を以下の内容で作成:

```yaml
name: pr-tests

on:
  pull_request:
    branches: [master]

concurrency:
  group: pr-tests-${{ github.event.pull_request.number }}
  cancel-in-progress: true

jobs:
  pr-tests:
    name: pr-tests
    runs-on: macos-26
    timeout-minutes: 30
    steps:
      - uses: actions/checkout@v4

      - name: Show toolchain versions
        run: |
          xcodebuild -version
          xcrun simctl list devices available | grep "iPhone 17" || true

      - name: Ensure tools (managed runner は preinstall を保証しない)
        run: |
          which pod || brew install cocoapods
          which swiftlint || brew install swiftlint

      - name: Restore secret plists
        env:
          KEYS_PLIST_BASE64: ${{ secrets.KEYS_PLIST_BASE64 }}
          GOOGLE_SERVICE_INFO_PLIST_BASE64: ${{ secrets.GOOGLE_SERVICE_INFO_PLIST_BASE64 }}
        run: |
          if [ -z "$KEYS_PLIST_BASE64" ] || [ -z "$GOOGLE_SERVICE_INFO_PLIST_BASE64" ]; then
            echo "::error::Secret plists unavailable (fork からの PR には secrets が渡らない)"
            exit 1
          fi
          echo "$KEYS_PLIST_BASE64" | base64 -d > app/Keys.plist
          echo "$GOOGLE_SERVICE_INFO_PLIST_BASE64" | base64 -d > app/GoogleService-Info.plist

      - name: Cache Pods
        uses: actions/cache@v4
        with:
          path: app/Pods
          key: pods-${{ runner.os }}-${{ hashFiles('app/Podfile.lock') }}
          restore-keys: pods-${{ runner.os }}-

      - name: Pod install
        working-directory: app
        run: pod install

      - name: Run make tests
        working-directory: app
        run: make tests

      - name: Sort gate (pbxproj が未 sort なら fail)
        run: git diff --exit-code -- app/LeafTimer.xcodeproj/project.pbxproj
```

設計メモ (実装者向け):
- `make tests` = precheck → sort → lint → unit-tests。CI 上で `make sort` が pbxproj を書き換えた = PR が sort 忘れ、を最終 step の `git diff --exit-code` で検知する (Issue #8 の再発防止)。
- simulator `iPhone 17` は macos-26 image の iOS 26.5 runtime に実在する (runner-images README で確認済み 2026-08-03)。
- precheck の `require 'xcodeproj'` は CocoaPods 1.17.0 の依存 gem として解決される。

Expected: `YAML OK`

```bash
gh api -X PUT repos/es0612/LeafTimer/branches/master/protection --input - <<'EOF'

    "strict": false,
```
