```ruby
  # `.font(` is deliberately not required, so `Font.system(size: 12)` is caught
  # too.
  #
  # Issue #108: two more shapes that also disable Dynamic Type —
  #   `Font.custom("Name", size: 15)`  and  `UIFont.systemFont(ofSize: 15)`
  #   (plus boldSystemFont / italicSystemFont / monospacedSystemFont …).
  # Same principle: the token right after `size:` / `ofSize:` must be a digit.
  # `Font.custom("Name", size: scaledSize)` and
  # `UIFont.preferredFont(forTextStyle:)` stay allowed.
  FIXED_FONT_SIZE = /
    (?:
      \.system\(\s*size:                 # .system(size: 15)
      | Font\.custom\([^)]*?,\s*size:     # Font.custom("Name", size: 15)
      | \.\w*[sS]ystemFont\(\s*ofSize:    # UIFont.systemFont(ofSize: 15) / boldSystemFont / …
    )
    \s*[0-9]
  /mx.freeze
```

`/x` (拡張モード) を使うので regex 内の空白・`#` コメントは無視される。既存の `/m` は維持。

**Interfaces:**
- Produces: `bash app/bin/ensure-cocoapods-version.sh [--check-only]` — `Podfile.lock` の `COCOAPODS: X.Y.Z` と `pod --version` を比較。一致なら exit 0。不一致時、`--check-only` なら exit 1 (インストールしない)、無指定なら `sudo gem install cocoapods -v X.Y.Z --no-document` を試みて再検証。
- Produces: `make unit-tests RESULT_BUNDLE=<abs path>.xcresult` — `RESULT_BUNDLE` 指定時のみ `-resultBundlePath` を付ける。常に `-enableCodeCoverage YES`。未指定時の挙動 (ローカル `make tests`) は coverage 計測が増える以外は従来通り。

- [ ] **Step 1: `ensure-cocoapods-version.sh` を作成する**

```bash
#!/usr/bin/env bash
# Issue #141: CI の CocoaPods を Podfile.lock の COCOAPODS 行と同じバージョンに揃える。
# バージョン差があると pod install の pbxproj 再シリアライズが変わり、
# pr-tests.yml 末尾の sort gate (git diff --exit-code project.pbxproj) が偽 fail する。
#
# Usage:
#   bash bin/ensure-cocoapods-version.sh              # 不一致なら gem install で揃える
#   bash bin/ensure-cocoapods-version.sh --check-only # 不一致なら exit 1 (インストールしない)
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
LOCK="${SCRIPT_DIR}/../Podfile.lock"
CHECK_ONLY=false
[ "${1:-}" = "--check-only" ] && CHECK_ONLY=true

want="$(sed -n 's/^COCOAPODS: *//p' "$LOCK" | tr -d '[:space:]')"
if [ -z "$want" ]; then
  echo "❌ ensure-cocoapods-version: COCOAPODS 行が $LOCK に無い" >&2
  exit 2
fi

have="$(pod --version 2>/dev/null | tr -d '[:space:]' || true)"
if [ "$have" = "$want" ]; then
  echo "✅ cocoapods $have matches Podfile.lock"
  exit 0
fi

echo "⚠️  cocoapods mismatch: have='${have:-none}' want='$want' (Podfile.lock)"
if $CHECK_ONLY; then
  exit 1
fi

sudo gem install cocoapods -v "$want" --no-document
hash -r
have="$(pod --version | tr -d '[:space:]')"
if [ "$have" != "$want" ]; then
  echo "❌ ensure-cocoapods-version: install 後も不一致 have='$have' want='$want'" >&2
  exit 1
fi
echo "✅ cocoapods $have installed to match Podfile.lock"
```

`chmod +x app/bin/ensure-cocoapods-version.sh` する。
